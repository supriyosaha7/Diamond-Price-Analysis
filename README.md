# Diamond Price Analysis and Machine Learning

## Project Overview

This project presents a statistical and machine learning based
analysis of diamond prices using a real-world diamond dataset.

The main objective is to investigate the relationship between
diamond price and its physical and quality-related characteristics.

## Dataset

The dataset contains information about diamond characteristics
such as:

- Carat
- Cut
- Color
- Clarity
- Depth
- Table
- Price
- Length
- Width
- Depth in mm

## Analysis Performed

- Descriptive Statistics
- Boxplot Analysis
- Frequency Distribution
- Histogram Analysis
- Scatterplot Analysis
- Correlation Analysis
- Multiple Linear Regression
- Regression Diagnostics

## Tools Used

- R
- RStudio
- Statistical Analysis
- Machine Learning
